# Horizon Solar Power Solutions - Official Website

Premium, high-converting, modern web portal designed for **Horizon Solar Power Solutions**, Kandakkai Road, Mayyil, Kannur, Kerala.

Built with **React 19**, **Vite**, **Tailwind CSS v4**, **Lucide Icons**, and **Canvas Confetti**.

---

## 🌟 Key Features

1. **Brand Identity & Verification**
   - Official brand logos and Mayyil store front imagery integrated.
   - Slogan: *"Powering A Brighter Tomorrow With Clean, Renewable Energy"*.
   - Sub-tagline: *"Clean Energy • Smart Future • Green Tomorrow"*.
   - Official GSTIN displayed across header & footer: `32AATFH8278G1ZV`.

2. **PM Surya Ghar: Muft Bijli Yojana Section**
   - Central Government Subsidy breakdown:
     - **1 kW System**: ₹30,000 Subsidy
     - **2 kW System**: ₹60,000 Subsidy
     - **3 kW+ System**: ₹78,000 Subsidy (Maximum direct DBT credit)
   - 4-step subsidy claim process guide.

3. **Interactive Solar Savings & ROI Calculator**
   - Interactive bimonthly bill slider (₹1,000 to ₹30,000+) with quick preset buttons.
   - Live calculation of:
     - Recommended system size (kW)
     - Roof area needed (sq. ft)
     - Monthly & 1-Year savings
     - 25-Year lifetime savings
     - CO₂ reduction & environmental impact
   - **One-click "Send Estimate to WhatsApp"** button with festive confetti and pre-filled estimate text.

4. **Comprehensive Solar Offerings**
   - **On-Grid Solar Systems** (KSEB Net Metering)
   - **Off-Grid Solar Systems** (100% blackout-proof battery storage)
   - **Hybrid Solar Systems** (Grid export + battery backup)
   - **Commercial & Industrial Rooftops** (High-yield enterprise solar)
   - **Solar Installation, Maintenance & AMC**
   - **Energy Saving Solutions & Audit**

5. **Life Before vs After Solar Comparison**
   - Direct comparison showcasing how bills drop from ₹4,500+ down to ₹120-240 meter rent.

6. **Tier-1 Brands & Regulatory Enlistment**
   - Waaree, Adani, Vikram Solar, Tata Power, Growatt, Deye, Solis, and KSEB Ltd.

7. **Authentic Mayyil Office & Ground Showcase**
   - Highlighting real showroom pictures on Kandakkai Road, Mayyil.
   - Direct Google Maps routing and working hours.

8. **Direct WhatsApp & Phone Integration**
   - Direct click-to-call: `+91 99471 60826` and `+91 82812 29530`.
   - Floating WhatsApp button with live ping badge.
   - Sticky mobile action bar for 1-tap booking.

9. **Lead Generation & Free Site Survey Booking Modal**
   - Capture name, mobile, location in Kannur, current bill, and desired capacity.
   - Instant routing to WhatsApp and local storage persistence.

## 🚀 Running Locally

```bash
# Start development server
npm run dev

# Open in browser
http://localhost:3000
```

## 📦 Production Build

```bash
# Build optimized static files
npm run build

# Preview build locally
npm run preview
```

The output files are generated in the `dist/` folder, ready for direct deployment to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any standard cPanel web hosting.
